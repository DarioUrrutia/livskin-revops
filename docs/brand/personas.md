- Arquetipo 7E es transversal — atraviesa los demás cuando ya son recurrentes

## 7E. Arquetipo emergente "Recurrente cálida" (transversal)

### Profile (detectado en chats reales — Lissie, Maryori, Luz Torres, Kelly, Siomara)
- **Característica:** atraviesa todos los arquetipos anteriores cuando ya son recurrentes
- **Comportamiento:** apoda a la doctora ("Clau", "Claudita", "Dra. Claudia"), paga efectivo o yape sin objeción, avisa proximidad ("Estoy en 5", "Estoy en tu puerta"), trae regalos físicos
- **Tolerancia:** delays 3-4h sin reclamo, audios branded sin sorpresa, stickers + emojis frecuentes

### Subtipo A: "Recurrente informal" (Lissie, Maryori, Kelly)
- Apoda Clau / Claudita
- Patrón temporal: chats de meses sin interrupción
- Comportamiento: avisa proximidad, paga al momento
- Tolera mensajes automáticos sin extrañeza

### Subtipo B: "Recurrente formal" (Luz Torres)
- Usa "Dra. Claudia" como tratamiento
- Frases formales: *"Le pregunto a qué hora la visito"* / *"Perdone no confirmé..."*
- Recuerda fechas especiales (mensaje post Día Madre)
- Usa sticker mano saludando 👋

### Tono ideal del bot Yossie

**Para subtipo A (informal):**
```
Hola {{1}} ☺️ Qué bueno saber de ti.
¿Qué necesitas?
```

**Para subtipo B (formal):**
```
Buen día Sra. {{1}} ☺️
¿En qué la puedo ayudar?
```

### Identificación automática
- **Cliente recurrente ERP** (≥3 ventas) → subtipo TBD (depende cómo escribe)
- **Detección de formalidad** en último mensaje:
  - Si usa "Dra." / "Sra." / "Le" / "Perdone" → subtipo B
  - Si usa "Clau" / "tú" / "hola" / minúsculas → subtipo A

### Política especial
- ✅ Skip greeting completo Yossie ("Soy Yossie, asistente de la Dra. Claudia Delgado...")
- ✅ Skip mención de "consulta gratuita"
- ✅ Acceso a precios directos sin disclaimer
- ✅ Permitir crédito (ver `precios-strategy.md` §3.3)
- ✅ Tolerancia a tono familiar (apodos OK)

## 8. Tier económico — visión transversal

### Bajo presupuesto
- **Vienen por:** PRP + Botox (entry points más accesibles)
- **Frecuencia:** baja, esporádica
- **Estrategia:** mantener catálogo de entry (Limpieza Facial S/80, PRP S/200) como hook
- **Conversión esperada:** algunas migran a tickets más altos con el tiempo

### Alto presupuesto
- **Vienen por:** todo el catálogo (Botox + AH + Hilos + Esperma Salmón + Exosomas)
- **Frecuencia:** alta (cada 3-5 meses)
- **Estrategia:** trato premium + acceso a tratamientos completos + crédito como retention

### High-value signal
> Doctora workbook: *"Usualmente ya saben a lo que vienen y ya se han hecho los procedimientos y no normalmente en nuestro local"*

→ Cliente que migró desde otra clínica. Detecta por:
- Hablan con términos técnicos
- Comparan productos/marcas
- No vacilan en precio
- Vienen por especialista, no por proximidad geográfica

## 9. Clientes problemáticos — anti-arquetipo

**Workbook + audio definen 5 patterns de "no atender preferentemente":**

1. **Negocian precio agresivamente** desde el primer mensaje
2. **Comparan obsesivamente** con otra clínica
3. **Cancelan última hora** repetidamente
4. **Esperan resultados imposibles** (*"borrar todas mis arrugas"*)
5. **Discuten contraindicaciones** (*"dame botox aunque esté embarazada"*)

### Política bot Yossie

**Detección de red flag:**
```javascript
const redFlagPatterns = [
  /m[áa]s barato|descuento|negociaci[oó]n|rebaja|baja precio/i,
  /(otra cl[íi]nica|munay|beysa|valderma).*(mejor|m[áa]s barato)/i,
  /cancel(o|amos|a) (otra vez|de nuevo)/i,
  /borrar todas? mis arrugas|cambiarme la cara|que me cambies/i,
  /embarazada|gestaci[oó]n|cancer/i,  // contraindicación → SIEMPRE escalate
];
```

**Acción:** Escalación a doctora con audit `red_flag_aggressive_behavior` + tag específico del pattern detectado. La doctora decide si atiende o no.

**Tono respuesta bot Yossie a red flag:**
```
{{1}}, te paso con la Dra. Claudia para que coordine directamente contigo ☺️

Te responde en breve.
```

(neutro, sin engancharse, sin entrar en defensa de precios o discusión)

## 11. Reglas para Bot Yossie por arquetipo

### Identificación

```javascript
function identifyArchetype(lead) {
  // Recurrente ERP (transversal #7E)
  if (lead.ventas_historicas >= 3) {
    return detectFormalityTone(lead.last_message) === 'formal'
      ? 'recurrente_calida_formal'
      : 'recurrente_calida_informal';
  }

  // Lead nuevo - detectar arquetipo por contexto del mensaje
  const text = lead.last_message.toLowerCase();
  if (text.match(/primera vez|nunca me he/)) return 'arquetipo_2_primeras_arrugas';
  if (text.match(/maquillaje no cubre|sólo lo veo yo/)) return 'arquetipo_3_high_value';
  if (text.match(/rápido|urgente|no tengo tiempo/)) return 'arquetipo_4_apuradas_pro';
  if (text.match(/resultados ya|cambios inmediatos/)) return 'arquetipo_5_apuradas_resultados';
  if (text.match(/joven|cuidado preventivo|mantener/) && lead.age < 30) return 'arquetipo_6_joven_entry';

  return 'arquetipo_default'; // Por defecto trato neutro tipo arquetipo #2
}
```
